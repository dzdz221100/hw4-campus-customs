# Campus Customs — HW4

A fictional Yale campus store ("Campus Customs") with a React + TypeScript storefront, a FastAPI backend, and a PydanticAI shop-assistant chatbot (`gpt-5.6-luna` via Portkey) that answers from a real SQLite catalogue/inventory database — never from guesses.

## Project structure

```
hw4/
├── AI_prompts.md          # Log of prompts/outcomes, one section per problem
├── requirements.txt        # Backend (Python) dependencies
├── .env.example             # Copy to .env and fill in PORTKEY_API_KEY
├── .gitignore
├── frontend/                # React + TypeScript + Vite app
├── backend/
│   ├── main.py               # FastAPI app and routes (products, auth, chat)
│   ├── agent.py               # PydanticAI agent setup, loop limits, audit logging
```

## Before you start: add the local data pack

This repo does **not** include `data/campus_customs.db` or `data/products/` (the product photos) — they're excluded from git on purpose (see "What's safe to push" below). Before running the backend, add your own copy:

```
hw4/data/campus_customs.db
hw4/data/products/<image files>
```

If you don't have this data pack, it's the same one provided with the assignment (a zip containing `campus_customs.db` and a `products/` folder of images) — unzip it into `hw4/data/`.

## Setup

### 1. Environment variables

```bash
cp .env.example .env
```

Then edit `.env` and set your real `PORTKEY_API_KEY`.

### 2. Backend

From the `hw4/` project root:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Then, **from inside `backend/`**, run:

```bash
cd backend
uvicorn main:app --reload --port 8000
```

The API is now at `http://localhost:8000` (check `http://localhost:8000/api/health`).

### 3. Frontend

In a separate terminal:

```bash
cd frontend
npm install
npm run dev
```

The site is now at `http://localhost:5173`.

## Trying it out

- Browse products on `/products`, click one for its detail page.
- Click the chat launcher (bottom-right) and ask things like "what hoodies do you have?" or "is the basic hoodie in stock in size M?" — the agent answers from the real database, never from guesses.
- Log in with the seeded test account: `test@campuscustoms.yale.edu` / `password`, or create a new account.

## What's safe to push to GitHub, and what isn't

**Push:** everything in this repo except what's listed below — `frontend/`, `backend/`, `output/` (including `app_check_images/` and `audit_trail.json`), `AI_prompts.md`, `requirements.txt`, `.env.example`, `.gitignore`, `README.md`.

**Never push** (all already excluded by `.gitignore`):
- `.env` — your real Portkey API key.
- `data/` — the local database and product photos (not this project's to redistribute, and unnecessary for grading the code).
- `.venv/`, `frontend/node_modules/`, `frontend/dist/` — local dependency/build artifacts, regenerated by `pip install` / `npm install`.
- `.DS_Store` and any `__pycache__/`/`*.pyc` files.
